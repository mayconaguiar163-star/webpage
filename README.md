# Apollo EVO V12 - Landing Page

Esta é uma landing page desenvolvida para apresentar o conceito do hipercarro Apollo EVO V12, com foco em design premium, visual esportivo e conteúdo técnico.

## Objetivo

A página tem como finalidade exibir:
- a identidade visual do veículo;
- informações sobre o modelo e suas características;
- uma apresentação visual moderna, voltada para público apaixonado por automóveis e performance.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts

## Estrutura do projeto

- `index.html`: estrutura da página com a apresentação do carro, imagens e especificações.
- `style.css`: estilos visuais, paleta de cores, layout, fontes e responsividade.

## Como visualizar localmente

1. Baixe ou clone este projeto em sua máquina.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Clique duas vezes no arquivo ou abra em um navegador.

Você também pode usar um servidor local simples, como:

```bash
python -m http.server 8000
```

Depois acesse:

```bash
http://localhost:8000
```

## Design e estilo

A página foi pensada com uma estética escura e esportiva, utilizando cores como preto, azul, amarelo, laranja e vermelho para transmitir performance, tecnologia e força.

## Informações do modelo

A página destaca:
- motor V12;
- potência expressiva;
- aceleração rápida;
- velocidade máxima elevada;
- aerodinâmica agressiva e visual futurista.
